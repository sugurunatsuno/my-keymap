# プライバシーと撮影

- capture はローカルPC上で処理します。自動アップロードはありません。
- 生動画は --save-video を明示したときだけ session.mp4 に保存します。
- 入力したテキストやキーの生イベントは収集しません。
- landmarks.csv.gz は手の特徴点と時刻を含みます。手の動きも個人に紐づく情報になり得るため、非公開で管理します。
- data/sessions/, data/private/, models/*.task, 動画形式は .gitignore で除外します。
- ブラウザのパスワード、個人チャット、通知が映る環境では記録しないでください。画角は机上の手とキーボードのみにしてください。
- 第三者の手や机が映り込む場合は、事前に許可を得てください。
- 共有するのは原則集計した統計と再現可能な実験設定だけにします。

.gitignore は過去にコミットされたファイルや、手動で強制追加したファイルを保護しません。アップロード前に git status と git diff --cached --name-only を確認してください。
