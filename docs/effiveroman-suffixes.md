# EffiveRoman語尾拡張の単語帳

初版: 2026-11-18

[effiveroman-suffixes.tsv](../lexicons/effiveroman-suffixes.tsv) に原典の語尾拡張35件を記録しています。これは入力方式の比較用データであり、Google日本語入力へそのままインポートするファイルではありません。

## 収録基準

- 元資料: [EffiveRoman 語尾拡張](https://3kyoson.hatenablog.com/entry/effive/2) の表を出典として記録
- 最初の英字と2番目の英字の組み合わせ、例えば `ds` →「です」
- TSV列: 入力 / かな / 系列 / 通常ローマ字 / 通常打鍵数 / 2打鍵との差 / 扱い / 注記
- 通常ローマ字は既存のkeylabの近似と同じ `し=si`、`しょう=syou`、`ん=nn`、`っ`は後続子音の重ねを基準とする
- 「2打鍵との差」は純粋な打鍵数の差であり、時間短縮を保証しない
- 候補はU/E交換案での頻度や運指による再評価前のもの。採否や順序に統計的な裏付けはまだない

## 初期試用の8候補

| 入力 | かな | 通常ローマ字 | 打鍵削減 |
|---|---|---|---:|
| `ds` | です | `desu` | 2 |
| `dn` | でした | `desita` | 4 |
| `ms` | ます | `masu` | 2 |
| `mn` | ました | `masita` | 4 |
| `ht` | して | `site` | 2 |
| `hn` | した | `sita` | 2 |
| `hs` | する | `suru` | 2 |
| `bs` | ません | `masenn` | 4 |

この8件は練習用に選んだ暫定候補。出現頻度ランキングではない。特に `bs` の採用効果などはコーパスで調査が必要。

## これからの評価

- 同じ日本語コーパスに対して35候補の出現数を数え、重複する文字列を二重計上しない
- 打鍵頻度とU/E交換後のキー位置、人差し指と中指の使いやすさを考慮する
- 初期試用8候補と、追加候補を段階的に比較する
- Lで小書きかなを入力する習慣は別のローマ字規則として維持する

## Google日本語入力への登録前に

「単語登録用の辞書」と「ローマ字変換テーブル」は異なる。今回の `tsv` は候補管理用で、IMЕへ直接登録する形式ではない。

Google日本語入力のローマ字テーブルは「入力 / 出力 / 次の入力」の3列。既存のローマ字規則を保つには、現在の設定をエクスポートしてバックアップしたうえで、それと候補を統合した完全なテーブルを作成する必要がある。35件だけを無条件にインポートしない。

原典では `dg` と `ds` は別の拡張規則との競合が生じることが明記されている。一般的なローマ字入力との衝突、`dga` や `dsa` のような後続キーがある場合、変換前の未確定状態などは実IMEで検証する。
